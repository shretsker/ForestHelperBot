# Telegram-бот «Лісовий архів»

Python Telegram-бот для звірів: приймає документи з порадами, відповідає на питання українською і вказує документ-джерело. Повністю запускається через `docker compose up --build`. Токени лише через env: `TELEGRAM_BOT_TOKEN`, `GROQ_API_KEY` (є `.env.example`).

## Стек
- Python 3.12, aiogram 3, Groq API (безкоштовна модель, напр. llama-3.3-70b-versatile; назва моделі в env)
- SQLite у Docker volume (документи, чанки, історія)
- Пошук: чанкінг + локальні мультимовні ембедінги (fastembed) або BM25 як запасний варіант. Groq ембедінгів не дає.
- Парсинг: pypdf, python-docx, txt

## Вимоги
1. Лише особисті повідомлення. Українська мова. Фото ігноруємо з поясненням.
2. Приймає PDF, DOCX, TXT (будь-який користувач). Розмір від однієї поради до путівника. Масштаб: сотні документів.
3. Метадані документа: рукавичка, частина лісу, тема, назва, автор, дата. Дістаємо з тексту й назви файлу (LLM-екстракція у JSON). Якщо рукавичку чи частину лісу визначити не можна, бот питає надсилача й не вгадує.
4. Новіша версія того самого документа (та сама рукавичка + частина лісу + тема) замінює стару: стара позначається неактивною і не потрапляє у відповіді. Якщо бот не певен, питає надсилача.
5. Запитання: шукаємо лише по активних документах. Відповідь будується тільки з знайденого контексту. Наприкінці завжди джерело: «— з документа "Назва" рукавички "X", надіслав(ла) Ім'я, ДД.ММ.РРРР».
6. Конфлікти: пріоритет рукавичка → частина лісу → загальне. Беремо найконкретнішу, загальну можна додати окремо з джерелом.
7. Якщо відповіді в документах немає: чесно «у документах цього немає», без вигадок. Якщо в питанні немає місця, а відповідь залежить від нього: перепитати.
8. Пам'ять: останні 5–6 повідомлень на користувача (зберігається в БД, діалог можна продовжити пізніше). Команда /reset очищає.
9. Незрозуміле повідомлення: перепитати і дати 1–2 приклади запитів. `/start` показує коротку інструкцію (один сценарій для всіх).
10. Ім'я: при першій відправці документа бот питає справжнє ім'я і зберігає. Для тих, хто лише питає, не питає. `/name` змінює ім'я. Інших налаштувань немає. Ім'я і дата надсилання показуються в джерелі.

## Приклади діалогів
- Успіх: «Скільки внесок під дубом і до якого числа?» → «4 жолуді з дорослого звіра на місяць, здати до 10 числа Кабанові... — з документа "Членські внески" рукавички "Під дубом"».
- Конфлікт: гриби в соснах → беремо «2–3 день після дощу» (хвойний ліс), загальне «шукати після дощу» додаємо з іншим джерелом.
- Відмова: питання без відповіді в документах → «У документах цього немає».
- Уточнення: «Скільки внесок?» → «Для якої рукавички?».
